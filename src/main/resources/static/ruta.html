Principios reactivos: repaso profundo

  1. Encapsulamiento: proteger el estado interno de los objetos.
  2. Abstracción: representar las características esenciales sin detalles de implementación.
  3. Herencia: reutilización de código y jerarquías de clases.
  4. Polimorfismo: múltiples formas de ejecutar un comportamiento.
  5. Interfaces: contratos que definen qué hace el sistema, no cómo.

Pregunta clave: Explica la diferencia entre composición y herencia. ¿Cuándo preferirías una sobre la otra?

Preguntas tecnicas para practicar

1) ¿Cuál es la diferencia entre una interfaz y una clase abstracta?

Respuesta esperada: Las interfaces definen contratos (qué hacer), mientras que las clases abstractas pueden definir estado y comportamiento base (cómo hacerlo parcialmente).

2) ¿Qué es el polimorfismo y cómo se aplica en Java?

Respuesta esperada: Es la capacidad de un objeto de tomar varias formas. En Java se aplica mediante la sobrescritura de métodos (overriding) y el uso de referencias de interfaces/clases base.

3) ¿Qué son los principios SOLID?

Respuesta esperada: Single responsibility, Open-closed, Liskov substitution, Interface segregation y Dependency inversion. Son guías para crear software mantenible.

Ejercicio 2: Herencia y Polimorfismo
