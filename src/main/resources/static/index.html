ScopeInstanciasPractica.java

El scope define la visibilidad de las variables.

System.out.println(
  ScopeInstanciasPractica.getTotalInstancias()
);
public class ScopeInstanciasPractica {
    private static int totalInstancias = 0;

    public ScopeInstanciasPractica() {
        totalInstancias++;
    }

    public static int getTotalInstancias() {
        return totalInstancias;
    }
}

Persona.java (Bases)

Clases y objetos: la base de Java. Atributos privados y constructores.

Persona p = new Persona("Ana");
System.out.println(p.saludar());
public class Persona {
    private String nombre;
    private int edad;

    public Persona(String nombre, int edad) {
        this.nombre = nombre;
        this.edad   = edad;
    }

    public String saludar() {
        return "Hola, soy " + nombre +
               " y tengo " + edad + " años.";
    }

    // Getters
    public String getNombre() { return nombre; }
    public int    getEdad()   { return edad; }
}

Relaciones de Clases

Agregación: cuando un objeto contiene a otro. El carrito "tiene" productos.

Tienda t = new Tienda();
t.agregarProducto(new Producto("Café", 2.5));
System.out.println(t.getTotal());
public class Tienda {
    private List<Producto> productos = new ArrayList<>();

    public void agregarProducto(Producto p) {
        productos.add(p);
    }

    public double getTotal() {
        return productos.stream()
            .mapToDouble(Producto::getPrecio)
            .sum();
    }
}

public class Producto {
    private String nombre;
    private double precio;

    public Producto(String nombre, double precio) {
        this.nombre = nombre;
        this.precio = precio;
    }
    public double getPrecio() { return precio; }
}

Abstracción

Clases abstractas para contratos base. Define el "qué" sin el "cómo".

abstract class Animal {
    abstract void hablar();
    public void dormir() {
        System.out.println("Zzz...");
    }
}
abstract class Animal {
    protected String nombre;

    public Animal(String nombre) {
        this.nombre = nombre;
    }

    abstract void hablar();

    public void dormir() {
        System.out.println(nombre + " duerme... Zzz");
    }
}

class Perro extends Animal {
    public Perro(String nombre) { super(nombre); }

    @Override
    void hablar() {
        System.out.println(nombre + ": ¡Guau!");
    }
}

class Gato extends Animal {
    public Gato(String nombre) { super(nombre); }

    @Override
    void hablar() {
        System.out.println(nombre + ": ¡Miau!");
    }
}

Configuración del Repositorio

Tu repositorio debe tener un archivo retos.json en la raíz:

{
  "retos": [
    {
      "id": "nivel1",
      "titulo": "Nombre del Reto",
      "descripcion": "Instrucciones...",
      "template": "public class Main { ... }",
      "output_esperado": ["Texto esperado"]
    }
  ]
}
  • id: Identificador único (nivel1, nivel2…)
  • template: Código inicial en el editor.
  • output_esperado: Fragmentos que la salida debe contener.
