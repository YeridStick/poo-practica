ScopeInstanciasPractica.java

El scope define la visibilidad de las variables.

System.out.println(ScopeInstanciasPractica.getTotalInstancias());
public class ScopeInstanciasPractica {
    private static int totalInstancias = 0;
    public ScopeInstanciasPractica() { totalInstancias++; }
    public static int getTotalInstancias() { return totalInstancias; }
}

Persona.java (Bases)

Clases y objetos: la base de Java. Aprende a definir atributos privados y constructores.

Persona p = new Persona("Ana");
System.out.println(p.saludar());
public class Persona {
    private String nombre;
    public Persona(String nombre) {
        this.nombre = nombre;
    }
    public String saludar() {
        return "Hola, soy " + nombre;
    }
}

Relaciones de Clases

Agregacion: cuando un objeto contiene a otro. El carrito "tiene" productos.

Tienda t = new Tienda();
t.agregarProducto(new Producto("Cafe", 2.5));
public class Tienda {
    private List<Producto> productos = new ArrayList<>();
    public void agregarProducto(Producto p) {
        productos.add(p);
    }
}

Abstraccion

Uso de clases abstractas para contratos base. Define el "qué" sin el "cómo".

abstract class Animal {
    abstract void hablar();
}
abstract class Animal {
    private String nombre;
    abstract void hablar();
    public void dormir() {
        System.out.println("Zzz...");
    }
}

class Perro extends Animal {
    void hablar() { System.out.println("Guau!"); }
}

Configuracion del Repositorio

Para cargar tus propios ejercicios, tu repositorio de GitHub debe contener un archivo retos.json en la raiz con esta estructura:

{
  "retos": [
    {
      "id": "nivel1",
      "titulo": "Nombre del Reto",
      "descripcion": "Instrucciones...",
      "template": "public class Main { ... }",
      "output_esperado": ["Texto esperado"]
    }
  ]
}
  • id: Debe coincidir con el nivel (nivel1, nivel2, etc).
  • template: Es el codigo inicial que aparecera en el editor.
  • output_esperado: Lista de fragmentos que la salida del programa debe contener para validar.
