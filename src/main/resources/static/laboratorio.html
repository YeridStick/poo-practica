🚀 Guía de inicio rápido con Podman

Para levantar este proyecto en tu entorno local usando Podman, ejecuta estos comandos:

# 1. Construir la imagen podman build -t poo-practica . # 2. Correr el contenedor podman run -p 8080:8080 poo-practica

Tip: Asegúrate de estar en la carpeta raíz del proyecto.

📁 Cargar ejercicios desde GitHub

Ingresa la URL RAW de un archivo .java en GitHub para cargarlo directamente en el editor.
