Documentacion desplegable de funciones

Cards para visualizar rapido que hace cada funcion y cuando conviene usarla.

map

Transforma elemento a elemento.

Ejemplo 
Flux.just(1,2,3).map(n -> n * 2)

flatMap

Encadena operaciones asincronas.

Ejemplo 
profile(id).flatMap(p -> score(p.id()))

concatMap

Mantiene orden en procesamiento secuencial.

Ejemplo 
Flux.just(a,b,c).concatMap(this::call)

zip

Combina fuentes en paralelo y espera a todas.

Ejemplo 
Mono.zip(a,b,c).map(t -> t.getT1())

timeout

Corta espera maxima para proteger latencia.

Ejemplo 
service().timeout(Duration.ofMillis(250))

sum en funcional

Para sumar en streams usa mapToInt(...).sum().

Ejemplo 
int total = nums.stream().mapToInt(n -> n).sum();
